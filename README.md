# Sweet-Mochi
Sweet Mochi es una aplicación móvil desarrollada en Flutter que simula una tienda de postres estilo kawaii . Permite a los usuarios registrarse, iniciar sesión y explorar diferentes postres organizados por categorías, con imágenes, precios y descripciones.

# Características principales

 Pantalla de login y registro
 Registro con imagen de perfil
 Catálogo de postres
 Categorías de postres
 Imágenes de cada producto
 Precios por postre
 Descripción detallada
 Navegación entre pantallas
 Diseño estilo kawaii / pastel
 
# Tecnologías utilizadas
Flutter 
Dart 
Image Picker 
Material Design

# Flujo de la aplicación
Pantalla de inicio 
Login o registro 
Catálogo de postres 
Selección de categoría 
Visualización de 3 postres relacionados 
Detalle con imagen, precio y descripción 

# Objetivo del proyecto

El objetivo de Sweet Mochi es practicar el desarrollo de interfaces móviles con Flutter, navegación entre pantallas y manejo de widgets personalizados, simulando una app real de tienda de postres.
